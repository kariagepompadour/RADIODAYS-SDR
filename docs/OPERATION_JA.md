# 操作ガイド（Cardputer ADV）— 詳細版

> **早見表は [QUICK_GUIDE_JA.md](QUICK_GUIDE_JA.md)（English: [QUICK_GUIDE_EN.md](QUICK_GUIDE_EN.md)）です。** Receiver Manager 画面の上部の「操作ガイド」ボタンからも開けます。
> 早見表の文面は `mac/manager/guide.json` の 1 か所だけにあり、このファイルとのキーの食い違いは自動テスト（`mac/tests/test_guide.py`）が検出します。
> このファイルは、挙動の背景・数値・診断画面などを含む詳細版です。Receiver Manager の使い方は早見表と README を参照してください。

状態灯: 画面右上の白いパネルに、`WiFi / PC / Kiwi` を含む5段の状態表示があります。通信の3灯は、**WiFi = 無線LAN、PC = PC側プログラム、Kiwi = KiwiSDR**への接続を示します。
（v1.7 で `M` から `P` に表示だけ変更しました。点灯の判定は変わっていません。）

## 使い方

1. 初回は Wi-Fi 一覧が出ます。`;` `.`（またはノブ）で選び ENTER → パスワード入力 → ENTER。TAB でパスワードの表示/非表示。最大 3 件を保存します。
2. PC（Mac / Windows）と Cardputer は**同じ LAN**に接続してください（ゲスト Wi-Fi など端末間通信が禁止のネットワークは不可）。
   PC は自動検出されます。検出できないときは `I` キーで PC の IP を手入力（起動したウィンドウに表示された `PC IP`）。
3. 下部の黒緑液晶の状態行で、どこで止まっているかが分かります:

   | 表示 | 意味 | 対処 |
   |---|---|---|
   | `Wi-Fi: …` | Cardputer が Wi-Fi に繋がっていない | `W` で設定 |
   | `PC: searching…` / `PC: connect failed`(HTTP -1) | PC側プログラムが見つからない/動いていない | パソコンで「Start RADIO DAYS」の起動ファイル（Mac: `Start RADIO DAYS Mac.command` / Windows: `Start RADIO DAYS Win.bat`）を起動、IP・ファイアウォールを確認 |
   | `PC: read timeout`(HTTP -11) | PC が応答しない | PC側プログラムを再起動 |
   | `Kiwi: connecting …` / `Kiwi: <エラー>` | PC側プログラムは動いているが KiwiSDR に繋がらない | 自動で次のサーバーへ切り替わります。`N` で手動切替 |
   | `Kiwi OK: <場所>` | 受信中 | |

### PC に繋がらないとき

Wi-Fi は繋がっているのに PC から3秒以上応答が無いと、通常画面が次の案内に切り替わります（短い途切れでは出ません）。PCから応答が戻ると、自動で通常画面に戻ります。

```
PC NOT CONNECTED
Start RADIO DAYS on your PC.
Check that its window stays open.
Could also be a wrong PC IP address
or a network problem (key I: set IP).
Last error: connection refused      ← 実際のエラー内容
PC IP: 192.168.1.23 (auto)          ← 使っている PC の IP（auto = 自動検出 / manual = 手入力）
10000.0 kHz AM  VOL 70              ← 今の設定（操作は引き続き可能）
```

- **原因は断定しません。** PC側プログラムが動いていない場合のほか、PCのIPの誤りやネットワーク障害でも同じ表示になります。最後の2行（エラー内容とIP）が切り分けの手掛かりです。`I`キーでPCのIPを入力・変更できます。
- 区別: **Wi-Fi が切れているとき**はこの案内ではなく、従来の `Wi-Fi: …` 表示。**PCは応答しているがKiwiSDRだけが失敗**しているときも、この案内は出ず、従来の`Kiwi: …`表示（状態行）です。
- 地球儀（`G`）を開いたときPCに繋がっていなければ、地球儀の右側にも同じ案内（短縮版）が出ます。

### 音声出力先（O キー、v1.3）

| 出力先 | 動作 |
|---|---|
| **Mac Speaker**（初期設定） | 従来どおり。Mac が KiwiSDR の音声をデコードして Mac のスピーカーから再生 |
| **Cardputer Speaker** | Mac が受信・デコードを続け、**デコード済みの音声を Wi-Fi で Cardputer に送り**、内蔵スピーカーで再生（Cardputer は RADIO DAYS 専用の Wi-Fi スピーカー） |

- 同時には鳴りません（切替時、片方を止めてからもう片方を始めます）。音量・ミュート（U135、`;` `.` `+` `-` `M`）はどちらでも同じ操作で、同じ設定値です。Cardputer 側の音量は Cardputer 本体で掛けるので、バッファの遅れなく即座に効きます。
- 右上パネルに `OUT PC` / `OUT ADV`（ADV = Cardputer）。Cardputer 出力を選んで鳴り始めるまで、下部の黒緑液晶の状態行に `ADV audio: waiting for PC / connecting / buffering / reconnecting / no memory` と理由が出ます。**メモリが確保できないときは自動的にPCスピーカーのままにして**表示します。
- Wi-Fi が切れると Cardputer が自動で再接続します（0.5→4 秒間隔）。復帰時は古い音声を捨てて遅延が溜まらないようにします。**Cardputer が落ちている間、Mac は自動では鳴りません**（突然 Mac が鳴らないよう、無音のまま状態行で知らせます）。Mac 側の Terminal に `Cardputer audio connected` / `lost` が出ます。
- 通信: 音声は TCP 8767 番（Mac 側）、16bit モノラル PCM・約 12kHz（約 192kbps、Wi-Fi の負担は小さい）。Mac のファイアウォールの許可ダイアログが出たら許可してください（8765 と同じ Python）。
- 音量の曲線は Mac と同じ (音量/100)² で、Cardputer の最大は U10 と同じ 192/255 に抑えています（小さなスピーカーの歪み防止）。**音量感は実機で聴いて調整が必要**です。
- `caffeinate`（Mac）: `Start RADIO DAYS Mac.command` は `caffeinate -i` 経由でプログラムを起動します。Windows 版では、プログラム自身が動作中だけスリープを防ぎます（終了すると解除）。プログラムが動いている間だけ Mac のアイドルスリープを防ぎ、終了すると（Ctrl+C・ウィンドウを閉じる・強制終了でも）自動的に解除されます。

### 診断画面（D キー）

音切れが「Wi-Fi のせい」か「Cardputer の処理のせい」かを区別するための数値です（約 0.5 秒ごとに更新。シリアルにも 5 秒ごとに出力）。

| 項目 | 意味と見方 |
|---|---|
| `BUF` | 受信バッファ量(ms)、受信フレーム数、`gaps 回/欠落数` = 連番の飛び（Mac が Cardputer の読み出し遅れでフレームを捨てた） |
| `NET maxgap` | フレーム間の最長無音(ms)。**150ms 超 = Wi-Fi／Mac 側の遅れ**、`reconn` = 再接続回数 |
| `PLAY under / over / rebuf` | `under` = 再生バッファ枯渇（受信が追い付かない）→ 再バッファして復帰。`over` = バッファ過多で捨てたフレーム（時計のずれ等） |
| `MAC sent / dropped / disc` | Mac が送ったフレーム、Mac 側で捨てた数（遅い読み手）、切断回数 |
| `HEAP` | 空きヒープ / 最小空き / 最大連続ブロック |

判断の目安: `under` が増え `maxgap` も大きい → Wi-Fi／Mac。`under` が増えるのに `maxgap` が小さい → 時計のずれか Cardputer 側の処理負荷。`over` が増える → 逆方向のずれ。`MAC dropped` が増える → Cardputer の読み出しが遅い。

### 通常画面（v1.10：銀色の金属ラジオ、黒地に蛍光緑の表示）

```
RADIO DAYS SDR
┌ SIGNAL ┐  ┌ VOLUME ┐  ┌ ● OUT PC   ○ OUT ADV ┐
│ 赤い針 │  │ 赤い針 │  │ ● WiFi ● PC ● Kiwi  │
└────────┘  └────────┘  │ ● MANUAL  ○ AUTO     │
                         │ ● AM ○ USB ○ LSB     │
                         │ ○ .1 ○ 1 ● 5 ○ 10 kHz│
                         └───────────────────────┘
┌ 白い目盛り（横に流れ、中央の赤い線で読む）────────┐
┌ 黒地・蛍光緑のESP32情報表示──────┬──────────┐
│       7100.0 kHz                 │ SAT 10/25│
│ Kiwi OK: Ironstone Range        │ 07:58 JST│
└─────────────────────────────────┴──────────┘
```

- **SIGNAL / VOLUME:** 左上の2つの角形アナログメーターです。SIGNALはKiwiSDRが報告するS値で動き、未接続では0へ戻ります。VOLUMEは**設定音量0〜100**を示し、実音量ではありません。ミュート時は針が0へ戻り、盤面が赤い`MUTE`になります。
- **右上の5段表示:** 上から①出力先、②通信、③MANUAL/AUTO、④AM/USB/LSB、⑤選局刻み幅です。通信だけは緑=正常、黄=接続中、赤=異常、暗色=未確認。それ以外はアンバー=選択中、暗色=非選択です。
- **選局刻み幅:** 画面には意味の分かりにくい`STEP`という単語を出さず、`.1 / 1 / 5 / 10 kHz`の選択肢をそのまま表示します。`1`〜`4`キーで変更できます。モードを変更したときは、AM=5 kHz、USB/LSB=1 kHzへ自動設定され、その後は自由に変更できます。
- **TUNING目盛り:** 横幅いっぱいの白い目盛りです。目盛り1本=現在の刻み幅、1本3 px、20本ごとに数字。赤線は中央に固定され、目盛りが滑らかに流れます（AUTO探索中はゆっくり）。
- **独立した2個の黒地・蛍光緑液晶:** 左の液晶は設定周波数と接続状態・受信機名・エラーです。右の小型液晶は、上段に曜日・日付・`JST`、下段に大きな時刻を表示するデジタル腕時計風です。両方とも太い黒枠ではなく薄い縁で埋め込み、外側の銀色ベゼルにねじがあります（左は上4本・下4本、時計は上2本・下2本）。同期前はプレースホルダーを表示し、時刻取得に失敗してもラジオは止まりません。
- 画面は「古い銀色のアナログチューナーへ、ESP32の情報液晶と独立した時計モジュールを後付けしたレストモッド」を意図しています。
- メモリ不足で描画用バッファを確保できないときは、従来の簡易画面に自動的に戻ります。

### MANUAL / AUTO 選局（`Tab` または `T`、v1.5）

起動時は MANUAL です（保存しません）。右上パネル3段目の `MANUAL` / `AUTO` のアンバー灯が現在の選局方式です。

| モード | U135 を回す | 動作 |
|---|---|---|
| **MANUAL** | 周波数が選択中の刻み幅で変わる | |
| **AUTO** | **回した方向**（右 = 高い方、左 = 低い方）へ自動で探す | 受信できそうな信号で自動停止。画面は `SCANNING >>>` / `<<<`、見つかると `SIGNAL FOUND +NN dB` |

- 探している間、周波数の数字とダイヤルが連動して動きます。止まった後、**もう一度同じ方向に回すと、その信号を飛ばして次の信号を探します。**反対に回すと向きを反転します。
- **途中で止める:** `Esc`（`` ` ``）または **U135 を押す**（AUTO で探している間は、押すとミュートではなく停止）。周波数を入力（`F`）・モード変更・受信機変更・MANUAL への切替でも止まります。
- 帯域の端（10 kHz / 30000 kHz）に着くと `END OF BAND`、KiwiSDR との接続が切れると `SCAN ENDED: KIWI LINK LOST` で終了します。
- **探す刻みは 5 kHz 以上**です（STEP が 5/10 kHz ならその幅。STEP が 0.1/1 kHz のときも 5 kHz。短波放送の間隔が 5 kHz のため。止まった後に STEP 1 や 0.1 で微調整してください）。
- **速さ:** 実際の KiwiSDR で 1 ステップ（5 kHz）あたり**約 1.4〜1.5 秒**です（後述の「測定」）。100 kHz の範囲で約 30 秒、1 MHz で約 5 分かかります。
- 停止の判定: ①雑音床（直近の測定の下位 20%）より **12 dB 以上**強く、②その山の頂点まで辿って戻り、③新しく測った 3 ブロックの**中央値が +10 dB 以上かつどれも +6 dB 以上**のとき。雑音が一瞬跳ねただけでは止まりません。弱い信号（雑音床 +9 dB など）は止まりません。受信状態はフェージングで変動するため、止まった信号が数分後には弱くなっていることもあります。
- Mac 側のプログラムが探索を行います（Cardputer は `/scan` で開始・停止を頼み、Mac が動かす周波数を表示します）。

### 操作キー

| 操作 | 動作 |
|---|---|
| U135 を回す | MANUAL: 周波数 ±ステップ / **AUTO: 回した方向へ自動で探す** |
| U135 を押しながら回す | 音量 ±5 |
| U135 を短く押す | ミュート（**AUTO で探している間は停止**） |
| `;` `.` または `+` `-` | 音量 ±5（`;`=↑ `.`=↓） |
| `M` | ミュート |
| `,` `/`（←→） | 周波数 −/＋ |
| `1` `2` `3` `4` | ステップ 0.1 / 1 / 5 / 10 kHz |
| **`Tab` または `T`** | **MANUAL ⇄ AUTO**（第一世代の `A` は AM に使っているため別キー） |
| **`Esc`（`` ` ``）** | AUTO の探索を止める |
| `A` `U` `L` | AM / USB / LSB |
| `F` | 周波数を数字で入力 |
| `G` | 地球儀で KiwiSDR を選ぶ |
| `O` | **音声の出力先を切り替え**（Mac スピーカー ⇄ Cardputer スピーカー）。選んだ出力先は保存され、再起動後も復元 |
| `D` | 診断画面（音切れの原因の切り分け。何かキーで戻る） |
| `N` `P` | 次/前の KiwiSDR（従来どおり） |
| `W` | Wi-Fi 設定 / `I` Mac の IP / `H` ヘルプ |

画面の **SIGNAL メーター**は KiwiSDR が報告した実際の受信強度（RSSI）です。
音量表示は、Mac に反映されたかどうかに関わらず「設定値」です（反映が遅れている間は Status 行に Mac の状態が出ます）。

## 地球儀（G キー）

U10 の Location 画面の地球儀描画（正射図法・陸地データ・回転の動き）を移植しました。UFO/衛星の演出は移植していません。

| 操作 | 動作 |
|---|---|
| `G` | 地球儀を開く（開くたびに Mac から最新の一覧を取得） |
| U135 を回す（または `;` `.` `,` `/`） | 受信機を順に選択。地球儀が選択地点を正面に回転 |
| U135 を短く押す / ENTER | 選択した受信機への接続を Mac に要求 |
| `Esc`（`` ` ``） | 何も変えずに元の画面へ戻る |
| 押しながら回す | 音量（U10 と同じ） |

- 右上の小さな**人工衛星**は第一世代の絵（飾り）です。衛星はふわふわ漂い、数秒おきに地球と電波をやり取りします（水色の波=地球から衛星へ、ランプの点滅、黄色の波=衛星から地球へ。1 方向ずつ）。これも飾りで、実際の通信状態とは連動しません。
- 黄色の点 = 登録受信機、**赤＋白の点 = 選択中**、**リング = 現在使用中**（緑=受信中、橙=接続中、赤=接続失敗）。
- 右側に名前・緯度経度・状態（`ON AIR` / `CONNECTING...` / `FAILED: 理由` / `REQUESTING...`）と、現在の受信機の状態（`NOW: …`）を表示します。状態は Mac の実際の接続状態そのものです。
- 同じ場所の受信機（Ironstone AU / AU2）は点が重なりますが、選択は別々にできます（右側に `1 of 2 at this site` と表示）。
- 要求した受信機に繋がらないと、Mac が自動で次へ切り替えます。そのとき地球儀のリングと `NOW:` が実際に繋がった受信機へ移ります。受信中になって 1 秒後に自動で元の画面へ戻ります。失敗したままのときは地球儀に残るので別の受信機を選べます。
- 位置が未確認の受信機（`lat`/`lon` なし）は地球儀に点が出ず、`position unverified` と表示されます。選択・接続はできます。
- メモリ不足で地球儀を作れないときは、文字の一覧（5 行/ページ）に切り替わります。
