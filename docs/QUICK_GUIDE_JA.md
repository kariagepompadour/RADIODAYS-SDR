# RADIO DAYS SDR - 操作ガイド

**RADIO DAYS SDR 操作早見表（v1.7）** · [English](QUICK_GUIDE_EN.md)

Cardputer ADV と PC（Mac / Windows）の基本操作の早見表です。詳しい説明は docs/OPERATION_JA.md（日本語）にあります。

## 基本操作

使う順番: ① パソコンの起動ファイルをダブルクリック（Mac: Start RADIO DAYS Mac.command ／ Windows 11: Start RADIO DAYS Win.bat）→ ② Cardputer ADV の電源を入れ、初回は Wi-Fi を選んでパスワードを入力 → ③ 画面右上の WiFi / PC / Kiwi の灯が緑になるのを待つ（パソコンは自動で見つかります）。パソコンと Cardputer は同じ LAN に接続してください。

| キー・操作 | |
|---|---|
| U135 回す | MANUAL: 選択中の刻み幅で周波数を変える。AUTO: 回した方向へ自動で探す |
| U135 を押しながら回す | 音量 ±5 |
| U135 を短く押す | ミュート（AUTO で探している間は探索を止める） |
| `;` `.` `+` `-` | 音量 ±5（; と + が上げる、. と - が下げる） |
| `M` | ミュート |
| `1` `2` `3` `4` | 選局の刻み幅を 0.1 / 1 / 5 / 10 kHz にする（右上の最下段に点灯表示） |
| `F` | 周波数を数字で入力（ENTER で決定） |
| `A` `U` `L` | モード AM / USB / LSB。モードを変更すると推奨刻み幅（AM = 5 kHz、USB/LSB = 1 kHz）になる。その後は 1〜4 で変更可能 |
| `W` | Wi-Fi の設定画面（一覧から選んでパスワードを入力） |
| `I` | PC の IP アドレスを手入力（自動で見つからないとき。起動したウィンドウに表示された PC IP） |
| `H` | キー一覧（Cardputer の画面） |
| `D` | 診断画面（音切れの切り分け） |

※ , と / は周波数の − / ＋（MANUAL のとき）です。画面の SIGNAL メーターは KiwiSDR が報告した受信強度、VOL メーターは「設定値」で実際の音の大きさではありません。

## 受信機（KiwiSDR）の選択

| キー・操作 | |
|---|---|
| `G` | 地球儀を開く（開くたびに PC から最新の一覧を取得） |
| U135 を回す `;` `.` `,` `/` | 地球儀の中で受信機を順に選ぶ（選んだ地点が正面に回る） |
| `ENTER` U135 を短く押す | 選んだ受信機への接続を PC に要求 |
| `Esc` `` ` `` | 何も変えずに地球儀を閉じる |
| `N` `P` | 地球儀を開かずに、一覧の次 / 前の受信機へ |

- 一覧の中身と順番は Receiver Manager で決めます（下の「Receiver Manager の使い方」）。保存したあと、Cardputer で G をもう一度押すと新しい一覧になります。
- 地球儀の黄色の点は登録された受信機、赤＋白の点は選択中、リングは使用中（緑 = 受信中、橙 = 接続中、赤 = 失敗）です。位置が未登録の受信機には点が出ませんが、選択・接続はできます。
- 要求した受信機に繋がらないときは、PC が自動で次の受信機へ切り替えます。

## MANUAL / AUTO 選局

| キー・操作 | |
|---|---|
| `Tab` `T` | MANUAL ⇄ AUTO を切り替える（起動時は MANUAL。保存されません） |
| U135 を回す | AUTO: 回した方向（右 = 高い方、左 = 低い方）へ探し、受信できそうな信号で止まる |
| `Esc` `` ` `` U135 を押す | 探索を止める |

- 止まったあと同じ方向にもう一度回すと、その信号を飛ばして次を探します。反対に回すと向きが反転します。
- 探す刻みは 5 kHz 以上です。1 ステップあたり約 1.4〜1.5 秒（実際の KiwiSDR での測定）かかります。細かい調整は止まったあと MANUAL で行います。
- 帯域の端では END OF BAND、KiwiSDR との接続が切れると SCAN ENDED: KIWI LINK LOST と表示して終わります。
- 受信状態はフェージングで変わるので、止まった信号が後で弱くなることがあります。

## 音声出力の切り替え

| キー・操作 | |
|---|---|
| `O` | 音声の出力先を PC スピーカー ⇄ Cardputer スピーカーに切り替える（選択は保存され、再起動後も復元） |

- 画面右上に OUT PC（PC スピーカー）と OUT ADV（Cardputer スピーカー）が並び、使っている方のランプが点灯します。同時には鳴りません。音量とミュートはどちらでも同じ操作です。
- OUT ADV で鳴り始めるまでは、下部の黒緑液晶の状態行に ADV audio: waiting for PC / connecting / buffering / reconnecting / no memory のいずれかが出ます。メモリが足りないときは自動で PC スピーカーのままになります。
- Cardputer が止まっている間、PC は自動では鳴りません（突然鳴らないため）。
- 音量の感じ方は実機で聴いて調整してください。

## Receiver Manager の使い方

起動ファイル（Start RADIO DAYS Mac.command / Start RADIO DAYS Win.bat）を開くと、ブラウザで Receiver Manager が自動的に開きます（起動のたびに毎回）。開かないとき・閉じたあとは、同じパソコンのブラウザで http://127.0.0.1:8780/ を開きます。ブラウザを閉じてもラジオは止まりません（止めるのは、起動したウィンドウで Ctrl+C）。ラジオを使うときは起動ファイルだけで足ります。「Open Receiver Manager Mac.command」/「Open Receiver Manager Win.bat」は、ラジオを起動せずに一覧だけ編集したいとき用で、すでに動いていれば既存の画面を開きます。この画面はそのパソコンの中だけで動き、他の端末からは開けません。

- 登録（左）: ≡ のドラッグか ↑↓ で並べ替え、× で登録解除。名前・短い名前・ホスト・ポート・緯度経度はその場で編集できます。この順番が地球儀の一覧の順番です（最大 32 台）。
- 候補（右）: 公開 KiwiSDR 一覧のスナップショットです。チェックを入れると登録、外すと解除。検索、「日本のみ」、国、登録済み/未登録で絞り込めます。候補が今接続できるかどうかは分かりません。
- 手動で追加: ホスト名とポートを直接指定します（自分の KiwiSDR など）。
- 保存して反映: 入力を検査してから保存し、動作中のプログラムにもすぐ読み込ませます。直前の保存は servers.json.bak と .servers_backups/（10 世代）に残り、「直前の保存に戻す」で戻せます。変更を破棄すると画面を開いたときの状態に戻ります。
- 反映後、Cardputer で G をもう一度押すと新しい一覧が見えます。使用中の受信機を外して保存すると、先頭の受信機に切り替わります。

### 確認ボタンと確認履歴

- HTTP確認: 受信機の Web サーバーが /status に答えるかだけを調べます（1 回の問い合わせ）。音声が受信できるかは分かりません。
- 音声確認（約 7 秒）: 実際に接続して音声ブロックが届くか調べます。相手の受信機の枠を一時的に 1 つ使うので、必要なときに 1 台ずつ押してください。一括実行はありません。
- 結果は「前回の確認」として日時つきで保存され、ブラウザを閉じて開き直しても、PC側プログラムを再起動しても表示されます（check_history.json）。HTTP確認と音声確認は別々に記録されます。未確認のものは「未確認」と表示されます。
- 「応答あり」「音声受信を確認」は、その日時の結果です。いま接続できることを保証するものではありません（公開受信機は混雑や停止で状況が変わります）。
- 画面を開いただけでは何も問い合わせません。「登録済みをHTTP再確認」「表示中の候補をHTTP一括確認」は押したときだけ動き、確認前に台数を示して承認を求めます。同時に問い合わせるのは最大 4 台で、途中で中止できます。

## 右上の5段状態表示

右上の白いパネルは、上から ① OUT PC / OUT ADV、② WiFi / PC / Kiwi、③ MANUAL / AUTO、④ AM / USB / LSB、⑤ 0.1 / 1 / 5 / 10 kHz です。通信の3灯だけは緑=正常、黄=接続中、赤=異常、暗い=未確認。それ以外は選択中がアンバー、非選択が暗色です。

| 灯 | 緑 | 黄 | 赤 | 灰 |
|---|---|---|---|---|
| WiFi | Wi-Fi 接続中 | 接続を試行中 | 未接続 | — |
| PC | PC側プログラムが応答 | Wi-Fi は繋がっているが PC が応答しない | — | Wi-Fi が未接続 |
| Kiwi | KiwiSDR に接続して受信中 | 接続中・再接続中 | 接続エラー | PC が応答していない（K は判定できない） |

## 接続トラブルへの対処

下部の黒緑液晶の状態行と、画面右上の WiFi / PC / Kiwi の灯で、どこで止まっているかを切り分けます。上から順に確認してください。

| 症状 | 考えられること / 対処 |
|---|---|
| W が赤・黄 / 状態行 Wi-Fi: … | Cardputer が Wi-Fi に繋がっていない。W キーで Wi-Fi を選び直す。 |
| P が黄 / PC: searching… / PC: connect failed | パソコンのプログラムが動いていない、パソコンの IP が違う、または別のネットワーク。起動ファイル（Start RADIO DAYS Mac.command / Start RADIO DAYS Win.bat）が動いているか確認し、I キーで、起動したウィンドウに表示された PC IP を入力。ゲスト Wi-Fi など端末間通信を禁止するネットワークは使えません。ファイアウォールの許可ダイアログ（Windows では「プライベート ネットワーク」を許可）が出たら許可します。 |
| 3 秒以上応答がなく PC NOT CONNECTED の画面になる | 原因は断定できません（PC側、IP の誤り、ネットワークのどれでも同じ表示）。最後の 2 行のエラー内容と PC IP が手掛かりです。PC が応答すると自動で通常画面に戻ります。 |
| P は緑で K が黄・赤 / Kiwi: <エラー> | PC側プログラムは動いているが KiwiSDR に繋がらない（満員、停止、パスワード、同じ IP からの 2 本目の拒否など）。自動で次の受信機へ切り替わります。N / P で手動切替、または G で別の受信機を選びます。同じ受信機に 2 つのプログラムから同時に繋がないでください。 |
| 繋がっているのに音が出ない | OUT PC / OUT ADV、音量、ミュートを確認。OUT PC なら PC の出力先（--sound-device）、OUT ADV なら状態行の ADV audio: … を見る。D キーの診断画面で音切れの原因が Wi-Fi か Cardputer かを切り分けられます。 |
| Receiver Manager が開かない / 「PC側プログラムに接続できません」 | 起動ファイル（Start RADIO DAYS Mac.command / Start RADIO DAYS Win.bat、または Open Receiver Manager Mac.command / Open Receiver Manager Win.bat）が動いているか確認し、同じパソコンのブラウザで http://127.0.0.1:8780/ を開く。別の端末や Cardputer からは開けません。--manager-port 0 で起動していると無効です。起動したウィンドウに「Receiver Manager は使えません」と出ているときは、ポート 8780 を別のプログラムが使っています（表示された確認コマンドで調べるか、--manager-port で別の番号を指定）。 |
| 保存した一覧が Cardputer に出ない | Cardputer で G をもう一度押す（開くたびに最新を取得）。Receiver Manager で保存が成功したか、画面上部の「未保存の変更」が消えているかを確認。 |
| 「応答あり」なのに受信できない | HTTP確認は Web サーバーの応答だけの確認で、前回の時点の結果です。音声確認を 1 台だけ試すか、混雑・パスワード・時間制限を疑ってください。 |
